
# NEXUS MEMÓRIA

Plataforma de mapa interativo dedicada à memória histórica e cultural do Recife, Pernambuco.

## Objetivo

Conectar lugares, histórias e referências culturais em uma plataforma digital de fácil acesso.

## Funcionalidades iniciais

- Mapa interativo com marcadores.
- Pesquisa de lugares históricos.
- Lista de locais cadastrados.
- Resumos informativos nos marcadores.
- Interface adaptável para computadores e celulares.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Leaflet
- OpenStreetMap

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no Visual Studio Code.
3. Instale a extensão Live Server.
4. Abra o arquivo index.html com o Live Server.
5. Mantenha a conexão com a internet ativa para carregar o mapa.

## Aviso

Os locais e textos da primeira versão são demonstrativos.
As coordenadas e informações históricas devem ser verificadas
com fontes confiáveis antes da publicação.

O projeto é independente e não representa uma parceria oficial
com Google Maps ou qualquer outra plataforma cartográfica.
